## Один шаг на компьютере владельца

Откройте файл через Win + R, вставив:

```text
notepad "%USERPROFILE%\TransferDriver-Inventory-NaePfa\metrics.private.json"
```

Это только открытие уже сохранённого файла, без запроса к базе и без изменения
данных. Сохраните файл у себя. Не отправляйте его, значения, снимок экрана или
хеш закрытого отчёта в чат/Git/CI. Если папка переименована, используйте папку,
указанную в вашем успешном запуске.

Сначала проверьте совпадение sourceCommit, databaseId, profile и окна времени
с receipt.public.json. При несовпадении остановитесь и сообщите только факт
несовпадения, без частного содержимого. Не смешивайте результаты разных запусков.

## Как читать 18 полей именно в legacy

| Поле внутри metrics | Что означает в этом профиле |
| --- | --- |
| vehicles | Число записанных автомобилей на момент чтения |
| missing_year | Нет хранения года: совпадение с vehicles ожидаемо; это не доказательство года конкретного авто |
| missing_color | Реальные NULL/пустые/пробельные цвета; цвет обязателен |
| missing_binding | Отсутствует слой bindings: значение обусловлено схемой |
| binding_input_mismatch | Ноль не подтверждает соответствие: binding ещё не хранится |
| binding_without_rule | Ноль не подтверждает полноту правил: binding ещё не хранится |
| never_assessed | Нет хранилища assessment: значение обусловлено схемой |
| without_current_trusted_assessment | Нет текущей trusted view: значение обусловлено схемой |
| current_candidate | Ноль из-за отсутствующего trust; не оценка фактической пригодности авто |
| current_manual_review | Ноль не означает, что ручная проверка никому не нужна |
| current_excluded | Ноль не означает, что неподходящих авто нет |
| declared_battery_electric | Ноль не доказывает отсутствие BEV: поле powertrain ещё не хранится |
| approved_without_matching_candidate | Старые approved без новой trusted-проверки; не команда снять им допуск |
| online_drivers | Записанное state=on_line; не доказательство физического нахождения водителя на линии |
| online_without_matching_candidate | Нет новой trusted-проверки; учитываются также отсутствующие/NULL ссылки на авто |
| active_assignments | state=active и revoked_at=NULL; не обязательно начавшиеся поездки |
| active_assignments_with_hold | Ноль не подтверждает отсутствие проблемы: holds слоя ещё нет |
| active_assignments_without_matching_candidate | Нет новой trusted-проверки; учитываются отсутствующие/NULL ссылки |

Счётчики пересекаются: их нельзя складывать в число проблемных машин.
Operational counts могут превышать vehicles из-за отсутствующих ссылок.
Legacy совместим с известными состояниями миграций 18 или 19; сама публичная
квитанция не выбирает одно из них. Она не является проверкой допуска на линию.

## Условный план — владелец выбирает ветвь у себя

| Условие в закрытом отчёте | Что подготовить к отдельному рассмотрению |
| --- | --- |
| vehicles, online_drivers и active_assignments равны нулю | План установки в пустой STAGING с проверкой точной версии и отсутствия новых записей перед выполнением; пустоту production из этого не выводить |
| Есть vehicles, но нет online_drivers/active_assignments | План сохранения старых записей и истории при обновлении схемы; очередь конкретных проверок, без выдуманных лет/силовых установок/автодопуска |
| Есть online_drivers или active_assignments | План совместимости и ручных действий по каждой затронутой связке в закрытой рабочей среде; aggregate SELECT не определяет, какие именно записи затронуты |
| Есть missing_color | Предложить уточнение цвета по материалам конкретного авто и установленную модерацию; не подставлять цвет по умолчанию |

Здесь не выбирается ветвь за владельца, не утверждаются действия и не публикуются
числа. Агрегаты не являются основанием массово отключить старые автомобили,
переназначить поездки, сменить pins или выдать исключения. При конкретном
критическом изменении действуют утверждённые правила повторной проверки,
запрета линии и ручного переназначения диспетчером. Автозамена водителя запрещена.

## Что входит в предложение следующего технического этапа

До любых записей нужен конкретный reviewable rollout proposal: точный target,
фактическая версия схемы и Worker, совместимые версии приложений, точный список
миграций и проверок сохранения данных/истории/пинов, ожидаемые отказы, порядок
остановки и восстановления. Legacy сам не определяет список миграций.
Если нужен backup/восстановление, порядок его получения и закрытого хранения
сначала предлагается отдельно; полный SQLite export вариантом A не разрешён.
Подготовка документа не является разрешением выполнять его.

В существующих проверенных ветках имеются миграции/контракты, но merge, remote
apply, seed/backfill и активация требуют отдельных решений. Перед будущим
выполнением используются свежие сведения в уже согласованных пределах:
отчёт от 24 ноября не доказывает неизменность состояния на дату выполнения.
Автоматического повторного чтения или новых произвольных запросов нет.

Класс выбирает система по утверждённой модели и правилу; водитель класс не
задаёт. OWNER exception не заменяет проверку документов и не делает BEV допустимым.
Комфорт: седан/кроссовер/лифтбек; Бизнес: седан с ранее утверждёнными crossover
исключениями Li Auto L7/L9; лифтбек в Бизнесе/Минивэне запрещён. Минимальные годы,
состав каталога 121/архив 116, текущие версии и правила не изменяются.
