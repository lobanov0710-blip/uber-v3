# Цвет кузова — обязательное поле

Утверждено владельцем 2026-11-17 прямым указанием. Исправляет прежнюю optional
формулировку; исходный утверждённый ТЗ и исторические receipts не переписываются.

Driver требует цвет кузова при создании/сохранении автомобиля. Backend требует
строку1..80 после trim, без внутренних управляющих символов. Missing/null/empty/
whitespace/нестроковое значение отвергаются. Частичный PATCH без color сохраняет
валидный существующий цвет; legacy null нужно заполнить перед сохранением.
Readiness не считает машину без цвета завершённой, возвращает missingColor.
Legacy read/DTO по-прежнему допускают отсутствие цвета, чтобы его исправить.

Никакой выдуманной палитры или автоматического цвета; новое название поля
«Цвет кузова». Не меняются выбор класса, pinned rule, новые OWNER-only права,
каналы распространения, инфраструктура и pause G1. Нет миграции/массового
перевода старых машин или самостоятельного разрешения merge/deploy.

Проверки: backend invalid create/patch и legacy read/fill; readiness;
существующий native UI create/edit проверяет отсутствие отправки без цвета,
контракт body и нормальное сохранение. Требуются полные CI/build/lint/security
и native D1; окончательные source/run/results фиксируются отдельным receipt.
