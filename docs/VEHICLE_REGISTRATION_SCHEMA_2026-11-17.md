# Подготовка регистрации к системному классу

Утверждено: класс определяет система; год указывает водитель и подтверждает
администратор; неподтверждённый автомобиль не получает допуск на линию.

## Реализовано в этом срезе

Миграция0020 разрешает `vehicles.class = NULL`, добавляет nullable model_year
и powertrain. Старые значения класса сохраняются без изменения, годы/установки
не выдумываются. Колонка класса изменяется через добавление временной колонки,
копирование значений, DROP COLUMN/ADD COLUMN и восстановление значений, без
DROP TABLE vehicles и каскадного удаления зависимостей. Изменение проверяется
также при транзакционном откате ошибки.

SQLite triggers запрещают approved при отсутствии класса. Репозиторий умеет
создать draft без класса и сохранить переданные доверенным серверным кодом
декларации года/установки. Чтение Driver me включает modelYear/powertrain и
сохраняет null вместо фиктивной строки класса. Внутреннее дополнительное чтение
metadata ограничено driver_id и vehicle_id; VIN/документы в нём отсутствуют.
Декларации не считаются подтверждением документов.

## Пределы и следующий шаг

Публичные POST/PATCH ещё используют прежний контракт и принимают vehicleClass;
его замена не выполнена данным PR. Новые поля не принимаются от водителя этими
старым POST/PATCH, запись новых полей здесь доступна только внутреннему
репозиторию. Нет администраторского подтверждения года/установки, окончательного
назначения класса, новых guards линии, прерывания поездки или изменения Android.
Старый Android DTO не готов к null-классу: включение нового создания draft
требует согласованного обновления API и клиента. Срез не выпускать как готовую
реализацию справочника и не включать новые drafts через старые клиенты.

Нет seed или удалённых миграций. Существующие approved автомобили этой
подготовительной миграцией не пересматриваются; требование блокировать линию
без подтверждённого года предстоит подключить отдельными серверными guards.
G1 paused; merge/deploy отсутствуют.

## Проверки

8 новых actual SQLite/HTTP cases: сохранение всех таблиц/связей при upgrade,
новый null-class draft, доверенные декларации, authenticated GET Driver me,
запрет approved без класса, owner-bound metadata read, ограничения полей и
rollback полной миграции. Добавлена проверка populated upgrade на native D1.
Итог полного CI и точный code SHA фиксируются отдельно после выполнения.
